# Publish static task pane assets

## Parent

`.scratch/publish-office-addin/PRD.md`

## What to build

Make the Office task pane, JavaScript engine, icons, and production manifest deployable through GitHub Pages as a complete static artifact.

## Acceptance criteria

- [ ] The GitHub Pages workflow publishes only the files required by the Office add-in.
- [ ] The production task pane URL loads over HTTPS.
- [ ] The published icon URLs return valid PNG files.
- [ ] The published `manifest.xml` can be downloaded from the Pages site.
