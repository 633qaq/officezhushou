# 📊 AI PPT 办公助手 v2.0

智能 PowerPoint / Word AI 助手，支持多种大模型，帮助编写和修改 PPT。

## ✨ 功能特性

### 📊 PPT 编写
- **生成大纲** — 输入主题，自动生成完整 PPT 大纲
- **生成完整内容** — 一键生成每页标题+要点+演讲备注
- **生成单页内容** — 选中主题，生成单页详细内容

### ✏️ PPT 修改 & 增强
- **精修润色** — 优化措辞，提升专业度
- **内容扩展** — 扩展要点，增加细节
- **精简缩写** — 提炼核心，缩减冗余
- **中英互译** — 商务级别翻译
- **演讲备注** — 自动生成演讲者备注
- **设计建议** — 配色/字体/动画/布局建议

### 🎨 PPT 风格模板
- 💼 商务专业 · 🎓 学术严谨 · 🎨 创意活泼 · ✨ 极简现代 · 🚀 科技感

### 🤖 多模型支持
- Gemini (Google 云端) · DeepSeek · GPT-4o · Claude · Groq · Ollama 本地

## 🚀 使用方式

1. 在 PowerPoint 中打开此插件（任务窗格加载项）
2. 选中幻灯片中的文字
3. 点击功能按钮或直接输入指令
4. AI 处理后，点击「📥 替换到PPT」

## 🔧 配置

点击右上角 ⚙️ 齿轮图标，配置：
- AI 服务商
- API Key（Ollama 无需）
- 自定义接口地址/模型
- PPT 默认风格
