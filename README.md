# AI PPT 办公助手 v2.0

智能 PowerPoint / Word AI 助手，支持多种大模型，帮助生成、修改和保存 PPT 内容。

## 功能特性

### PPT 生成
- 生成大纲：输入主题，自动生成完整 PPT 结构
- 生成完整内容：一键生成每页标题、要点和演讲备注
- 生成单页内容：围绕某一页主题生成详细内容

### PPT 修改与增强
- 精修润色：优化措辞，提升专业度
- 内容扩展：扩写要点，补充细节
- 精简缩写：提炼核心，压缩冗余内容
- 中英互译：面向商务表达的双语转换
- 演讲备注：自动生成讲稿备注
- 设计建议：给出版式、配色、字体和动画建议

### 风格模板
- 商务专业
- 学术严谨
- 创意活泼
- 极简现代
- 科技感

### 多模型支持
- Gemini
- DeepSeek
- GPT-4o
- Claude
- Groq
- Ollama

## 使用方式

1. 在 PowerPoint 中加载此插件
2. 输入主题，或读取当前选中的幻灯片文字
3. 点击功能按钮生成、润色或扩写内容
4. 将结果复制、写回 Office，或保存到服务端文档

## 配置项

- AI 服务商
- API Key（Ollama 可不填）
- 自定义接口地址
- 自定义模型名称
- PPT 默认风格
- 服务端地址与登录信息

## 目录结构

| 文件 | 说明 |
